# Зелёная полка

Веб‑магазин с доставкой овощей, фруктов и зелени: каталог, корзина, оформление с проверкой адреса на карте, трекинг заказа и роли для персонала.

**Автор:** Масловский Артём, ИСП-423т  

**Стек:** Python 3, Flask, Jinja2, SQLite, Leaflet (карта), vanilla JS.

## Что потыкать на сайте

Краткий маршрут, если открыли демо и хотите посмотреть весь функционал.

### Без входа

1. **Главная** (`/`) — бренд, ссылки в каталог и на зону доставки.
2. **Каталог** — фильтр по категориям, карточки товаров, кнопка **«В корзину»** (счётчик меняется без перезагрузки).
3. **Корзина** — количество, сумма, переход к оформлению.
4. **Зона доставки** (`/delivery`) — полигон и точки магазинов на карте Leaflet.
5. **Где мой заказ?** — ввод кода формата `ZP-******` (код покажет админка или появится после своего заказа).

### Покупатель (`user1` / `user1`)

1. Войти через **Вход**.
2. В каталоге набрать корзину → **Оформить**.
3. На **checkout** кликнуть по карте в зоне доставки, проверить адрес, отправить заказ — появится код `ZP-…`.
4. **Личный кабинет** — сохранённые адреса (если добавляли при заказе).
5. **Трекинг** — вбить свой код и посмотреть статус и историю.

### Администратор (`admin` / `admin`)

1. **Админ** → список заказов: смена статуса, назначение курьера.
2. **Каталог** — новая позиция, правка цены/остатка, **стоп‑лист** (скрыть товар с витрины).
3. Можно открыть трекинг по коду любого заказа и сверить с панелью.

### Сборщик (`user2` / `user2`)

1. **Панель сборщика** — очередь заказов на комплектацию, перевод по статусам до передачи курьеру.
2. Доступен трекинг по коду.

### Курьер (`user3` / `user3`)

1. **Курьер** — назначенные доставки, смена статуса «в пути» / «доставлен».
2. На карточке заказа — ориентир по адресу (по данным оформления).

### На что обратить внимание

- Корзина режется по **остатку на складе** — попробуйте заказать больше, чем `stock_qty` у товара.
- Точка **вне зоны** на карте при оформлении не пройдёт серверную проверку.
- Без входа **админ**, **сборщик** и **курьер** редиректят на страницу входа.

## Карта и зона доставки

Конур зоны и координаты магазинов подгружаются из виджета [конструктора 2ГИС](https://platform.2gis.ru/map-constructor).

- Переменная `DGIS_MAP_WIDGET_URL` в `config.py` (или в окружении)
- Кэш: `app/static/data/delivery-map.json`
- На сервере адрес проверяется функцией `point_in_delivery_zone` (`app/geo.py`)

После смены контура в 2ГИС перезапустите приложение.

## Конфигурация (переменные окружения)

| Переменная | Назначение |
|------------|------------|
| `SECRET_KEY` | Ключ сессии Flask (обязательно сменить на проде) |
| `DATABASE_URL` | URI БД (по умолчанию SQLite в корне проекта) |
| `DGIS_MAP_WIDGET_URL` | URL виджета 2ГИС с полигоном зоны |
| `SITE_PUBLIC_URL` | Публичный базовый URL (для абсолютных ссылок при деплое) |
